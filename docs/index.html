🧠 5 Default Native Model Architectures

Sovwave includes 5 native trainable model architectures operating over continuous wave fields:

📖 1. Wave LLM

Autoregressive sequence modeling predicting next-token continuous wave packets through golden spiral context memory.

out = generate_text(model, tok, "wave packet", max_new_tokens=8)

🖼️ 2. Image Generation

Continuous 2D spatial surface de-interference synthesizing pixel manifolds from latent harmonic states.

img = generate_image(model, "cymatic pattern"; height=32, width=32)

🧊 3. Text-to-3D

Volumetric radiance fields $(x, y, z) \mapsto (\sigma, R, G, B)$ mapped across continuous coordinate lattices.

vol = generate_3d(model, "sacred solid"; resolution=8)

🛡️ 4. Jev Decision Engine

100% Hallucination-Immune

Jev reads language but never writes it. It ingests an application's data state alongside predefined questions and returns type-safe, structured probabilistic decisions (:boolean, :category, :rubric). Because it cannot generate open-ended text, it is completely immune to traditional text hallucinations. 

decisions = jev_decide(
    model, 
    Dict("temp" => 84.5, "pressure" => 3.2), 
    ["Should cool?", "Risk score?"]; 
    question_types=[:boolean, :rubric]
)

🎬 5. Text-to-Video

Spatio-temporal wave dynamics evolved across frames $t$ and serialized directly to lossless Dual-Stream MKV/MP4 files.

generate_video(model, "vortex dynamics", "vortex.mkv"; frames=16, fps=4)

🔍 Model Reading & Introspection API

Full visibility into quantum node lattices, learned wave amplitudes, phases, and frequencies:

using Sovwave

model = WaveModel(default_config())

# Read architecture metrics
n_layers = num_layers(model)            # 4
p_count = parameter_count(model)        # 24,836 continuous wave parameters

# Print formatted summary table
model_summary(model)

# Deep inspection of individual layers & disk files (.mkv)
details = layer_details(model, 1)
file_info = inspect_model("trained_model.mkv")
