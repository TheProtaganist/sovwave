Sovwave.jl Architecture & Theory

Comprehensive mathematical foundations, operational workflows, multi-modal data processing, audio sonification, physical wave layers, and losslessly serialized video model execution.

📦 1. Installation

Sovwave runs smoothly on standard commodity CPUs without CUDA drivers, proprietary BLAS binaries, or high-power GPUs.

Julia Environment

Requires Julia 1.9 or later. Install directly via the Julia Package Manager:

# In the Julia REPL, press ']' to enter Pkg mode:
pkg> add https://github.com/TheProtaganist/sovwave

# Or programmatically from code:
using Pkg
Pkg.add(url="https://github.com/TheProtaganist/sovwave")
using Sovwave
using Sovwave.WaveML
using Sovwave.WaveML.SovwaveFunctions

System & External Dependencies

  • FFmpeg (Recommended): Required for optical video frame extraction, lossless MKV container attachment embedding, and real-time audio playback.
  • ALSA / PulseAudio / WASAPI: For 432 Hz / 963 Hz live sound sonification.
  • Python / C++ / Node.js Runtimes: Located in runtimes/, requiring zero Julia runtime dependencies at inference time.

⚙️ 4. Data Processing & Wave Tokenization

Sovwave eliminates discrete scalar token IDs ($1, 2, \dots, N$) that lack physical meaning. Instead, data is mapped directly into acoustic sound waves:

Phonetic Continuous Wave Tokenization

Every word and phoneme is mapped to its characteristic vocal tract formant frequencies: \(F_1\) (jaw height), \(F_2\) (tongue position), and \(F_3\) (lip rounding).

\[ s(t) = \frac{1}{\sqrt{3}} \left[ \sin(2\pi F_1 t) + \sin(2\pi F_2 t) + \sin(2\pi F_3 t) \right] \cdot e^{-t/\tau} \] 
using Sovwave.WaveML

tok = phonetic_tokenizer()
wave_packet = text_to_phonetic_wave(tok, "Hello world")
# Encodes actual spoken formants at 963 Hz carrier with pause cadences for punctuation

Harmonic Subword Tokenization

Maps Unicode code-points and frequent BPE subwords to golden ratio harmonic frequencies:

\[ f(u) = \Omega \cdot \Phi^{\frac{u \pmod{12}}{12}} \cdot \left(1 + \frac{u}{\Phi} \pmod 1 \cdot 0.5\right), \quad \phi(u) = 2\pi \cdot \frac{u}{\Phi} \pmod{2\pi} \]

🏋️ 7. Training & Wave Relaxation

How models learn without discrete matrix backpropagation:

Adjoint Phase-Conjugate Wave Reflection

When a prediction wave \(\hat{\psi}\) strikes target wave \(y\), it generates a phase-conjugate reflection error wave:

\[ e^{(L+1)} = \frac{y - (\hat{\psi} \cdot y)\hat{\psi}}{\|\psi^{(L)}\|_2}, \quad \delta E_i = e_i \cos(E_i) \] \[ \Delta A_{i, j} = \eta \cdot \delta E_i \cos(\phi_{i, j}) x_j, \quad \Delta \phi_{i, j} = -\eta \cdot \delta E_i A_{i, j} \sin(\phi_{i, j}) x_j \] \[ e_j^{(L)} = \sum_{i} \delta E_i A_{i, j} \cos(\phi_{i, j}) \]

🌊 8. How Layers Work vs Traditional Neural Networks

A fundamental comparison between discrete matrix deep learning and continuous physical wave computing:

Traditional Neural Networks

\[ y = \text{GELU}(W \cdot x + b) \]
  • Mechanism: Millions of discrete multiplications and additions of scalar numbers.
  • Weights: Arbitrary unconstrained floating-point numbers without physical units.
  • Hardware: Massive GPU clusters consuming megawatts of energy.
  • At Zero Input (\(x=0\)): Non-zero bias terms produce static baseline drift.

Sovwave Continuous Wave Layers

\[ E_i = \sum_{j=1}^{D} A_{i, j} \cos(\phi_{i, j}) x_j, \quad \psi_i = \sin(E_i), \quad \hat{\psi} = \frac{\psi}{\|\psi\|_2} \]
  • Mechanism: Wave interference, acoustic phase coherence, and spatial harmonics.
  • Weights: Physical amplitudes \(A_{i, j} \ge 0\) and spatial phases \(\phi_{i, j} \in [0, 2\pi)\).
  • Hardware: CPU-native fluid dynamics, zero GPU requirements.
  • Zero-DC Guarantee: When \(x=0\), \(E_i = 0\) and \(\sin(0) = 0\), guaranteeing zero static DC noise across arbitrary depth.

🏆 10. Optimizations & Loss Functions

Tournament-winning algorithms powering Sovwave's continuous efficiency:

Tournament Grand Champion Power Resonance Loss (\(p=1.4\))

Standard dot product loss \(\mathcal{L} = 1 - \rho\) suffers from shallow gradients near convergence. The Grand Champion Power Resonance algorithm scales resonance by power \(p=1.4\), amplifying steep gradients:

\[ \rho = \hat{\psi} \cdot y, \quad \rho_{\text{enhanced}} = \operatorname{sgn}(\rho) \cdot |\rho|^{1.4}, \quad \mathcal{L} = \operatorname{clamp}(1.0 - \rho_{\text{enhanced}}, 0.0, 2.0) \]
